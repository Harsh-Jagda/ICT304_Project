System Configuration Guide

To ensure the WMS Forecasting and Risk engines work correctly, please follow the formatting guidelines below for both your data and your supply chain settings.

1. CSV Dataset Format Inventory Data

Required Columns:

  • sales: Historical daily quantity. This is the primary target for the LightGBM model.

Classification Columns (For Risk Analysis):

  • cat_id: Category identifier. Note: This must match the keys in your Lead Time JSON.
  • item_id: Unique SKU identifier.
  • dept_id / store_id: Optional organizational identifiers.

Technical Features:

  • sell_price, date, event_name_1: Improving forecasting accuracy.

2. Lead Time JSON Format Supply Chain Settings

To customize Risk Analysis (Safety Stock & ROP), upload a JSON file with the structure shown below. Each key represents a cat_id.

{
    "PHARMA": {
        "lead_time_days": 5,
        "service_level_z": 1.96,
        "description": "Critical medical supplies."
    },
    "SURGICAL": {
        "lead_time_days": 3,
        "service_level_z": 1.645,
        "description": "Standard surgical tools."
    },
    "FOODS": {
        "lead_time_days": 1,
        "service_level_z": 2.326,
        "description": "Perishable items, high service level."
    }
}

Configuration Details:

  • lead_time_days: Number of days between order and delivery.
  • service_level_z: The Z-score for statistical confidence (e.g., 1.96 for 95% service level).
  • description: Optional text for your internal reference.
Pro Tip: You can upload multiple JSON files (e.g., standard.json vs emergency.json) and switch between them on the Dashboard to simulate different supply chain scenarios.

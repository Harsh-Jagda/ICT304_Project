System Configuration & Data Guide

To ensure the **LightGBM Forecasting** and **Regional Risk** engines operate with maximum accuracy, your uploaded files must adhere to the following specifications.

1. Enhanced CSV/Parquet Format ML Feature Set

The system now utilizes a 16-feature model. While the engine will attempt to fill missing values, including these columns directly yields the best results:

Categorical (IDs):

  • state_id: Critical. Enables regional filtering (e.g., CA, TX, WI).
  • cat_id: Used to link with JSON lead times.
  • item_id / dept_id / store_id: Specific SKU & Location tracking.
  • event_name_1 / event_type_1: Holiday/Promotion tracking.

Numerical (Vitals):

  • sell_price: Current item price.
  • lag_7 / lag_28: Sales figures from 1 & 4 weeks ago.
  • rolling_mean_7 / rolling_std_7: Short-term demand volatility.
  • rolling_mean_28: Long-term stability trend.
Data Tip: Ensure state_id values are clean (no trailing spaces). The system uses these to generate the dynamic dropdowns on your Dashboard and Risk reports.

2. Lead Time JSON Configuration Risk Parameters

Upload a .json file to define how the system calculates Reorder Points (ROP) and Safety Stock. The cat_id in your CSV must match the keys in this file.

{
    "FOODS": {
        "lead_time_days": 2,
        "service_level_z": 2.326,
        "description": "Perishables - requires 99% confidence."
    },
    "HOBBIES": {
        "lead_time_days": 7,
        "service_level_z": 1.645,
        "description": "Non-essential - standard 90% confidence."
    },
    "HOUSEHOLD": {
        "lead_time_days": 5,
        "service_level_z": 1.96,
        "description": "Bulk goods - 95% confidence level."
    }
}

3. How Calculations Work

  • Daily Forecast: Generated by the LightGBM model using the 16-feature matrix.
  • Safety Stock: Calculated as: Z-Score × Demand StdDev × √(Lead Time).
  • Reorder Point (ROP): Calculated as: (Daily Forecast × Lead Time) + Safety Stock.
  • Days of Cover: The ratio of current (or ROP) inventory against projected daily demand.
Admin Controls: Use the "Activate Config" tool on the Dashboard to swap between different JSON files. This allows you to test "Stress Scenarios" (e.g., doubling lead times) to see how regional risk levels change instantly.
